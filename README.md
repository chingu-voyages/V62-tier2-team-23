# 🧭 PathPilot

PathPilot is an AI-powered learning path app built with React and deployed on Vercel. Users tell the app their career goal, skill level, study time and target timeframe, and it generates a step-by-step learning path they can track as they go.

**Project Link:** [https://v62-tier2-team-23.vercel.app](https://v62-tier2-team-23.vercel.app)

## ⚡ Features

- Enter a career goal (for example Frontend Developer or Data Scientist)
- Choose your current skill level: Beginner, Intermediate or Advanced
- Set your available study time (hours per day or per week) and target timeframe
- Get a personalized learning path generated by Google Gemini
- Track progress by clicking a step to mark it complete, with a live progress count and bar
- Form validation with clear error messages on every form
- Sign up and login pages
- Responsive design for phones, tablets and desktops

## 📝 How it Works

1. Go to the home page and click **Generate Your Learning Path**.
2. Fill in the form with your goal, skill level, study time and timeframe.
3. The form is validated, then sent to a serverless function that asks Gemini for a learning path.
4. You land on the results page, where the first step is marked **In progress** and the rest are **Not started**.
5. Click a step to mark it complete. The next unfinished step becomes **In progress**, and the progress count and bar update.
6. Click **Generate New Path** to start over with a different goal.

## 🔒 Keeping the API Key Safe

The Gemini API key is never sent to the browser. The React app calls `/api/generate`, a Vercel serverless function, and only that function reads the key. The function also tries a faster model first and falls back to a second model if the first one fails or takes too long.

## 💻 Run It Locally

1. Clone the repo and install dependencies:
```bash
   git clone <your-repo-url>
   cd path-pilot
   npm install
```
2. Create a `.env` file in the project root:
```
   GEMINI_API_KEY=your_key_here
```
   Get a key from [Google AI Studio](https://aistudio.google.com). Never commit this file, and don't prefix the name with `VITE_`.
3. Install the Vercel CLI and start the app:
```bash
   npm install -g vercel
   vercel dev
```
4. Open the address it prints, usually `http://localhost:3000`.

`npm run dev` also starts the site, but it doesn't run the `api/` folder, so generating a path only works with `vercel dev`.

## 🚀 Deployment

The app is deployed on Vercel.

1. Import the repo in Vercel.
2. Add the environment variable `GEMINI_API_KEY` under **Settings → Environment Variables**.
3. Deploy, or redeploy after changing environment variables.

`vercel.json` rewrites the app's routes (`/inputForm`, `/results`, `/login`, `/signup`) to `index.html` so refreshing those pages works. If you add a new page, add a matching rewrite.
